# kafka/ — Script vận hành Kafka

- `start_kafka.sh` — khởi động Kafka (KRaft mode, không cần Zookeeper)
- `stop_kafka.sh` — dừng sạch
- `create_topics.sh` — tạo 3 topic: `comments_raw` (3 partition), `comments_scored`, `comments_dlq`

Cách chạy lại từ đầu: xem `README.md` gốc của dự án (Task 5 sẽ bổ sung).
